# Invoice Management System

A complete Invoice Management System developed using **Core PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap**.

## Features

- Client Management
- Add, Edit & Manage Company Profiles
- GST Invoice Generation
- Export Invoice Generation
- GST Number Based Client Details
- Direct Invoice Email
- Invoice Management & Tracking
- Business Reports
- Client & Invoice Records
- Responsive Bootstrap Interface

## Technology Stack

- PHP (Core PHP)
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap

## Invoice Features

The system allows users to create professional GST and Export invoices, manage invoice details, and maintain complete client records.

Users can also search or fetch client information using their **GST Number**, send invoices directly through email, and view useful reports for business analysis.

## Project Purpose

This Invoice Management System is designed to simplify billing, client management, GST invoicing, and business reporting in one centralized platform.
